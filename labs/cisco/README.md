# Cisco Curriculum Labs (Rebuilt)

Labs that mirror topics from Cisco NetAcad (ITN, SRWE, ENSA). Each one is REBUILT from scratch in my own Packet Tracer. No Cisco-authored lab files are redistributed. Shared here are:

- The topic names (not copyrightable).
- Generic Cisco IOS CLI commands (available in Cisco's public documentation).
- My own topology layout, device addressing, and verbal explanation.

## Numbering scheme

Numbers follow Cisco course module order as a sort prefix:

| Range | Course |
|-------|--------|
| 01-17 | ITN (Introduction to Networks) |
| 20-35 | SRWE (Switching, Routing, Wireless Essentials) |
| 40-54 | ENSA (Enterprise Networking, Security, Automation) |

Gaps (18-19, 36-39, 55+) are reserved so sub-topics or add-on labs can be inserted later without renumbering.
