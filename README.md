## About this repo

This repo is dedicated **only** to CCNA 200-301 exam prep. Notes, lab configs, and topology screenshots are organized by CCNA topic and aligned with the *Official Cert Guide Library, 2nd Ed.*

Some physical devices and base configs are shared with [Homelab_Router-on-a-Stick](https://github.com/Aj-Networks/Homelab_Router-on-a-Stick), but the two repos are kept logically separate:

- **Homelab_Router-on-a-Stick** = general home lab (router-on-a-stick design, ongoing tinkering).
- **CCNA_Home_Lab** (this repo) = exam-focused labs only.
